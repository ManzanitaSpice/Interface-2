## Siempre actualizado

INTERFACE comprueba nuevas versiones automáticamente y verifica su firma antes de instalarlas.

Este repositorio contiene únicamente:

- Instaladores oficiales.
- Firmas de actualización.
- Metadata pública para los canales stable y beta.

> El código fuente, las claves de firma y los secretos de publicación se mantienen privados.
